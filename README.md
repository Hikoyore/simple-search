# Simple search

Утилита для поиска текста внутри архивов (`.zip`, `.7z`, `.rar`) на больших дисках. Рассчитана на десятки тысяч архивов и объёмы в единицы терабайт: читает только нужные файлы, не распаковывает всё подряд, кеширует просканированное, умеет группировать результаты.

![screenshot](https://github.com/Hikoyore/simple-search/blob/main/preview/preview.png?raw=true)

## Возможности

- Поиск подстроки внутри файлов выбранных расширений (`.ini`, `.cfg`, `.json`, …).
- Поддержка `.zip`, `.7z`, `.rar`, включая вложенные архивы.
- Регистронезависимый поиск по умолчанию.
- Учёт регистра и regex — не поддерживаются намеренно, чтобы не плодить ложные срабатывания на больших объёмах.
- Пропуск уже просканированных архивов через SQLite-чекпоинт (по пути + mtime + size).
- Три режима просмотра результатов: «Все совпадения», «По архиву», «По строке».
- Промежуточное автосохранение результатов в CSV рядом с программой.
- Возможность пропустить текущий архив (например, если он слишком большой).
- Статус-бар показывает прогресс, скорость чтения и текущий архив.
- Контекстное меню: открыть папку с архивом, открыть архив, извлечь найденный файл, копировать путь / имя файла / строку.
- Интерфейс на русском и английском.

## Требования

- Python 3.9+.
- PySide6.
- Внешние утилиты:
  - **7-Zip** (`7z.exe`) — для `.7z`.
  - **UnRAR** (`UnRAR.exe` из состава WinRAR) — для `.rar`.
  - `.zip` обрабатывается встроенным `zipfile`, внешние утилиты не нужны.

Если `7z.exe` или `UnRAR.exe` не найдены ни в `PATH`, ни в стандартных папках установки, соответствующие форматы будут пропущены, а сверху появится предупреждение.

## Установка

```bash
pip install PySide6
```

## Запуск
```bash
python main.py
```
